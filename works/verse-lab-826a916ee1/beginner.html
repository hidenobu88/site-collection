01やさしい

Verseってどんな言語?

Verse(ヴァース)は、Epic Games社が開発したプログラミング言語です。もともとは「Fortnite」の中で、 誰でも自分だけのミニゲームを作れる「UEFN(Unreal Editor for Fortnite)」のために生まれました。 今後はUnreal Engine全体でも使えるようになる、注目の新言語です。

たとえ話でわかる Verse

プログラミング言語を「料理のレシピを書くための言葉」だと考えてみましょう。
既存の言語(たとえばC++やPython)は、何十年も前に決まったレシピの書き方を少しずつ直しながら使っています。 一方でVerseは、「これからの100年、みんなで同じ大きなキッチン(メタバース)を使い続けるなら、 最初から使いやすいレシピの書き方を作り直そう」という発想で、ゼロから設計された新しいレシピの書き方です。

Verseには、開発チームが大切にしている3つの合言葉があります。

🧱

It's Just Code(全部ふつうのコード)

むずかしく見える機能も、特別な魔法の構文ではなく、いつもの部品の組み合わせで表現されます。

🔁

Just One Language(言語はひとつだけ)

「先に処理される特別なコード」と「あとで実行されるコード」の区別がありません。見たままが全てです。

🌍

Metaverse First(みんなで使う世界が最優先)

たくさんの人が同時に遊ぶ、ひとつの大きな世界で動くことを前提に設計されています。

📘
このサイトの元ネタについて

このサイトはEpic Games公式の学習書「Book of Verse」の内容をベースに、専門用語をすべて日常のたとえ話に置き換えて再構成したものです。正確さはそのままに、わかりやすさを大幅にアップさせています。

02やさしい

すべてが「式」という考え方

Verseを理解するうえで、いちばん大切な考え方がこれです──Verseでは、コードのほとんどすべてが「式(しき)」だということ。 式とは、「実行すると必ず何かの値になるもの」のことです。

たとえ話でわかる「式」

自動販売機を思い浮かべてください。お金を入れてボタンを押すという「操作」をすると、 缶ジュースが出てくるという「結果」が必ず返ってきますよね。

Verseでは、if文もfor文も、そして関数の呼び出しも、すべてがこの自動販売機のように「何かを実行すると、値が出てくる」仕組みになっています。 他の多くの言語では「if文は値を返さない特別な命令」ですが、Verseではif式そのものが値になるのです。

verse
# if式がそのまま「値」になる例
Message := if (Score >= 60) then "合格" else "不合格"
Print(Message)

if (条件) then 値A else 値B という書き方で、条件がtrueなら値A、falseなら値Bが「式の答え」として返ってきます。 自動販売機に「合格ボタン」と「不合格ボタン」があって、点数という名のコインを入れたら、どちらかの答えがコトンと出てくるイメージです。

✨
なぜこれが便利なの?

「値を返す部品」をどんどん組み合わせられるので、コードがブロック遊びのように組み立てやすくなります。この考え方は中級・上級に進むほど威力を発揮します。

📝 演習問題

上のコードを参考に、Scoreが80以上なら"Sランク"、そうでなければ"Aランク"をRankという変数に入れて表示するコードを書いてみましょう。

verse
Rank := if (Score >= 80) then "Sランク" else "Aランク"
Print(Rank)
03やさしい

変数と定数──名前つきの箱

プログラムの中でデータを覚えておくには、「変数(へんすう)」を使います。Verseでは、箱に「開け閉めできる箱」と 「一度閉じたら二度と開かない箱」の2種類があると考えるとわかりやすいです。

たとえ話でわかる 変数

不変(変えられない)の値は、「油性ペンで名前を書いた開かずのカプセル」です。一度中身を入れたら、二度と変えられません。
可変(変えられる)の値は、「鍵つきロッカー」です。鍵(varという魔法の言葉)を持っていれば、何度でも中身を入れ替えられます。

Verseでは「基本は開かずのカプセル」がルールです。うっかり中身を書き換えてバグを生む事故を防ぐため、 変えたいときだけ、はっきりと「これはロッカーです」と宣言する必要があります。

verse
# 開かずのカプセル(不変)。 := で「型を推測しながら」中身を決める
PlayerName := "ゆうた"
MaxScore : int = 100        # 型を自分で書いてもよい

# 鍵つきロッカー(可変)。var を付けて宣言する
var Coins : int = 225
set Coins += 100            # set を使うと中身を書き換えられる
Print("所持コイン: {Coins}")  # → 325
書き方意味あとで書き換え
Name := 値不変(型は自動で推測)❌ できない
Name:型 = 値不変(型を自分で指定)❌ できない
var Name:型 = 値可変(型指定は必須)✅ setで可能
⚠️
つまずきポイント

varで変数を作るときは、:=(型を自動で決める書き方)が使えません。必ずvar Name:型 = 値のように、型をはっきり書く必要があります。

✏️ ミニクイズ
Q. 一度決めたら絶対に変えられない値のことを、このサイトでは何のたとえ話で説明した?
正解はB。「開かずのカプセル」は不変の値、「鍵つきロッカー」はvarを使った可変の値でしたね。
📝 演習問題

Gemsという名前でint型の可変変数を作り、初期値50からsetで30増やして、結果をPrintで表示してみましょう。

verse
var Gems : int = 50
set Gems += 30
Print("{Gems}")   # → 80
04やさしい

基本のデータ型

箱(変数)に何を入れられるかを決めるのが「型」です。Verseの基本の型を、身近なものにたとえて覚えましょう。

🔢

int 整数

おはじきの「数」のように、割り切れる整数だけを表します。例: 225、-3

💧

float 小数

コップに入った水の「量」のように、細かい端数まで表せる数です。例: 98.6

🍕

rational 分数

ピザを3等分したときの「1切れぶん」のように、割り算の答えを丸めずぴったり正確に持てる数です。

🚦

logic 真偽値

信号機の「進め/止まれ」のように、trueかfalseの2択だけを表します。

📛

string 文字列

名前が書かれた「短冊」のように、文字の並びを表します。例: "ゆうた"

verse
Coins : int      = 225
Health : float   = 98.6
Half   : rational = 5 / 2       # 割り算は正確な分数になる(2.5に丸められない)
IsAlive : logic  = true
PlayerName : string = "ゆうた"

# rational は Floor / Ceil で整数に変換できる
Floor(Half)   # → 2 (切り捨て)
Ceil(Half)    # → 3 (切り上げ)
🍕
なぜ rational(分数)が必要なの?

float(小数)はコンピューターの中で「だいたい」の値になってしまうことがあります。ピザを3人で分けるときに「1/3切れ」を正確に持ちたい場合は、丸め誤差の出ないrationalが活躍します。

📝 演習問題

Age(int, 10)、Height(float, 140.5)、IsStudent(logic, true)の3つの変数を定義し、 それぞれPrintで表示してみましょう。

verse
Age : int = 10
Height : float = 140.5
IsStudent : logic = true

Print("{Age}")
Print("{Height}")
Print("{IsStudent}")

演算子で計算する

演算子は「電卓のボタン」です。数字や値を組み合わせて、新しい値を作ります。

記号意味例
+ - * /足す・引く・かける・割る3 + 4 → 7
= <>等しい・等しくない3 = 3 → true
< <= > >=大小比較5 > 3 → true
and / or / not論理のかけ算・たし算・反転true and false → false
verse
var Coins : int = 100
set Coins += 50           # Coins = Coins + 50 の短縮形
set Coins -= 20           # 引く

IsRich := Coins > 100 and Coins < 1000
Print("お金持ち判定: {IsRich}")
🧮
豆知識: 文字列や配列も「+」でつなげられる

"おはよう" + "ございます"のように、+は文字列の連結にも使えます。電卓のボタンが、文房具のノリのように働くイメージです。

verse
Price : int = 800
DiscountedPrice := Price * 9 / 10
Print("{DiscountedPrice}")   # → 720
06やさしい

関数という「魔法の機械」

関数は、材料(引数)を入れると決まった手順で加工して、結果(戻り値)を出してくれる「機械」です。 一度作れば、何度でも同じ手順を呼び出せます。

たとえ話でわかる 関数

ジューススタンドのミキサーを想像してください。りんごを入れると、りんごジュースが出てくる。バナナを入れると、バナナジュースが出てくる。 「何を入れるか(引数)」によって、「何が出てくるか(戻り値)」が変わる、決まった手順の機械です。

verse
# Fruit(材料)を受け取り、string(ジュース名)を返す機械
MakeJuice(Fruit : string) : string =
    "{Fruit}ジュース"

Print(MakeJuice("りんご"))   # → りんごジュース

# 2つの材料を受け取る機械
Add(X : int, Y : int) : int = X + Y
Print(Add(3, 4))              # → 7

# 複数の手順がある機械はブロックで書く
Greet(Name : string) : string =
    Message := "ようこそ、{Name}さん!"
    Message                    # 最後の式が「機械の出力」になる

関数の書き方は 関数名(材料名:型, ...) : 戻り値の型 = 手順 という形が基本です。 手順が複数行になるときは、最後に書いた式がそのまま「機械の出力」になります。これも「すべてが式」の考え方の延長です。

✏️ ミニクイズ
Q. 関数を「ジューススタンドのミキサー」にたとえたとき、「引数」にあたるのはどれ?
正解はB。ミキサーに入れる果物が「引数(材料)」、出てくるジュースが「戻り値(結果)」でしたね。
📝 演習問題

2つのint(X, Y)を受け取り、大きい方の値を返す関数Biggerを作ってみましょう。

ヒント: if式が「値になる」ことを思い出しましょう(02章)。
verse

    if (X > Y) then X else Y

07やさしい

条件分岐 if / else

条件によって行動を変えたいときに使うのがif式です。天気予報を見て服を選ぶときの、頭の中の判断とそっくりです。

たとえ話でわかる if

「もし雨が降っていたら、傘を持つ。そうでなければ、日傘か何も持たない。」
これがそのままVerseの if ... else ... です。「もし(if)」の後ろの条件が成立するかどうかで、進む道が分かれます。

verse
Age : int = 12

if (Age >= 20):
    Print("大人料金です")
else:
    Print("こども料金です")

# 複数の条件をカンマでつなげると「すべて成立したら」の意味になる
if (Age >= 6, Age < 12):
    Print("小学生ですね!")
🔍
先取り予告

実はVerseのifは、単なる条件分岐以上のことができる、とても奥深い仕組みです。「条件」の部分に入れられるのはtrue/falseだけではありません。詳しくは中級編・第1章「失敗という考え方」で解説します。

📝 演習問題

Temperature(int)が30以上なら"暑い"、そうでなければ"過ごしやすい"とPrintするコードを書いてみましょう。Temperatureは35にしてください。

verse
Temperature : int = 35

if (Temperature >= 30):
    Print("暑い")
else:
    Print("過ごしやすい")
08やさしい

くり返し for / loop

同じ処理を何度もくり返したいときに使うのが、forとloopです。

たとえ話でわかる くり返し

forは「クラス全員の名簿を、上から順番に1人ずつ呼んでいく」イメージです。名簿(配列)の人数ぶんだけ、自動でくり返します。
loopは「タイマーが鳴るまで縄跳びを跳び続ける」イメージ。自分で「もうやめ!」(break)と言わない限り、永遠にくり返します。

verse
Members := array{"たろう", "はなこ", "けんじ"}

# for: 配列の中身をひとつずつ取り出す
for (Name : Members):
    Print("こんにちは、{Name}さん")

# loop: 自分で止めるまで無限にくり返す
var JumpCount : int = 0
loop:
    set JumpCount += 1
    Print("{JumpCount}回目のジャンプ!")
    if (JumpCount >= 10):
        break                # 10回跳んだら終了
🛑
つまずきポイント

loopはbreakで止めるのを忘れると「永遠に終わらない縄跳び」になってしまいます。loopを書いたら、必ずどこかに終わる条件(break)があるか確認しましょう。

📝 演習問題

array{"りんご", "ばなな", "みかん"}という配列を作り、forを使って 「果物: 〇〇」という形式で1つずつPrintしてみましょう。

verse
Fruits := array{"りんご", "ばなな", "みかん"}

for (Fruit : Fruits):
    Print("果物: {Fruit}")

配列とマップ

複数のデータをまとめて持ちたいときに使う、2種類の「収納ボックス」を紹介します。

たとえ話でわかる 配列とマップ

配列(array)は「下駄箱」です。1番、2番、3番…と番号(インデックス)が決まっていて、順番に靴(データ)が並んでいます。
マップ(map)は「国語辞典」です。「りんご」という見出し語(キー)を引くと、「赤い果物」という意味(値)が出てきます。番号ではなく、名前で中身を探せます。

verse
# 配列(下駄箱) ── 順番に並んだ同じ型のデータ
Fruits : []string = array{"りんご", "ばなな", "みかん"}
Print(Fruits[0])              # → りんご (0番目から数える)

# マップ(辞書) ── 見出し語(キー)から値を引く
Scores : [string]int = map{
    "たろう" => 90,
    "はなこ" => 85
}
Print(Scores["たろう"])       # → 90
配列(array)マップ(map)
たとえ下駄箱(番号で探す)辞書(言葉で探す)
探し方Fruits[0]Scores["たろう"]
向いている場面順番が意味を持つデータ名前で素早く検索したいデータ

"たろう" => 90のマップに、あなた自身で"はなこ" => 85と"けんじ" => 78も加えた3人分のScoresマップを作り、 "けんじ"の点数だけをPrintしてみましょう。

verse

文字列を組み立てる

変数の中身を文章に埋め込みたいときは、波かっこ{ }を使った「文字列補間(ほかん)」がとても便利です。

たとえ話でわかる 文字列補間

# { } の中に変数名を書くだけで自動的に埋め込まれる

Print(Message)  # → ゆうたさんのスコアは95点です!

11実践

UEFNの部品とVerseをつなぐ

ここまでで、Verseという「言葉」の基本文法を覚えました。最後の仕上げに、実際のUEFN(Unreal Editor for Fortnite)の ワールドに置けるボタンや踏むと反応するエリアと、あなたが書いたコードをつなげてみましょう。 自分のコードで実際にゲームの中の物が動く瞬間は、プログラミングでいちばん楽しい瞬間です。

たとえ話でわかる デバイスとVerse

UEFNに置く「ボタン」や「トリガー(踏むと反応するエリア)」は、電池が入っていないおもちゃのようなものです。 見た目はちゃんとしたボタンでも、配線(Verseコード)をつながないと何も起きません。

あなたが書くcreative_deviceというクラスは、この「配線係」です。「このボタンが押されたら、この処理を実行してね」 という配線図を1枚書くだけで、ワールド中のボタンやトリガーに命が吹き込まれます。

🔘ボタンを押したら反応させる

まずはUEFNの「Button Device(ボタン)」をワールドに1つ置いたと仮定して、押されたら文字を表示するだけの、いちばんシンプルな配線を書いてみましょう。

verse — my_first_device.verse
using { /Fortnite.com/Devices }
using { /Verse.org/Simulation }

# creative_device を継承すると、UEFNのワールドに置ける「装置」になる
my_first_device := class(creative_device):

    # @editable を付けると、UEFNの画面上でボタンを「割り当て」できるようになる
    @editable
    MyButton : button_device = button_device{}

    # OnBegin はゲーム開始時に自動で1回だけ呼ばれる、配線係の出社時刻
    OnBegin<override>()<suspends> : void =
        MyButton.InteractedWithEvent.Subscribe(OnButtonPressed)

    # ボタンが押されるたびに、押した人(Agent)を連れて呼ばれる
    OnButtonPressed(Agent : agent) : void =
        Print("ボタンが押されました!")

このコードをUEFNのVerseデバイスとしてワールドに置き、詳細パネルでMyButtonの欄に実際のボタンを割り当てるだけで、 ゲームを開始してそのボタンを押すと、すぐに動作を確認できます。

🚶踏むと反応するエリア(トリガー)を使う

ボタンと並んでよく使われるのが「Trigger Device(トリガー)」です。プレイヤーがそのエリアに足を踏み入れるだけで反応します。

verse
my_trigger_device := class(creative_device):
    @editable
    FloorTrigger : trigger_device = trigger_device{}

    OnBegin<override>()<suspends> : void =
        FloorTrigger.TriggeredEvent.Subscribe(OnFloorStepped)

    OnFloorStepped(MaybeAgent : ?agent) : void =
        Print("誰かがエリアを踏みました!")
🎁
見覚えのある「?」ではありませんか?

トリガーが送ってくる?agentは、実は04章で学んだ「型」の仲間で、「踏んだ人がいるかもしれないし、コード側から直接呼ばれて誰もいないかもしれない」福袋のような値です。この「?」の中身の取り出し方は、次の中級編・第2章でくわしく学びます。

デバイス反応するきっかけイベント名
Button Device(ボタン)プレイヤーが「使う」操作をするInteractedWithEvent
Trigger Device(トリガー)プレイヤーがエリアに入る/コードで発火TriggeredEvent
🔌
配線の基本パターンを覚えよう

①@editableでデバイスを受け取る → ②OnBeginで.Subscribe(処理する関数)を登録する → ③関数の中に実際の処理を書く。この3ステップは、この先どんなデバイスを使っても変わらない「お決まりの型」です。中級編・上級編では、この型に乗せてアイテム付与やテレポート、プロップ(物体)を動かす処理を追加していきます。

📝 演習問題

この章のボタンのコードを参考に、CountButtonというボタンを押すたびに、可変変数PressCountを1ずつ増やして 「ボタンは〇〇回押されました」と表示するcounter_deviceを作ってみましょう。

ヒント: 03章のvarとsetを組み合わせます。
verse
counter_device := class(creative_device):
    @editable
    CountButton : button_device = button_device{}

    var PressCount : int = 0

    OnBegin<override>()<suspends> : void =
        CountButton.InteractedWithEvent.Subscribe(OnPressed)

    OnPressed(Agent : agent) : void =
        set PressCount += 1
        Print("ボタンは{PressCount}回押されました")

📝 総合チャレンジ問題

配列Names := array{"ゆうた", "みお", "けん"}をforでくり返し、 それぞれの名前に対して「〇〇さん、こんにちは!」というメッセージを作って返す関数GreetAllを作り、 結果を1件ずつPrintしてみましょう。

ヒント: 06章の関数、08章のfor、10章の文字列補間をすべて組み合わせます。
verse
Names := array{"ゆうた", "みお", "けん"}

GreetAll(Name : string) : string =
    "{Name}さん、こんにちは!"

for (Name : Names):
    Print(GreetAll(Name))
