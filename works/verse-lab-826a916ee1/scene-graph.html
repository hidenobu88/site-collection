01やさしい

シーングラフってなに?

UEFNでワールドに置く箱・扉・浮島などの物体を「Prop(プロップ)」と呼びます。Verseコードから このプロップを制御する仕組み全体を、UEFNでは「Scene Graph(シーングラフ)」と呼びます。

たとえ話でわかる Scene Graph

creative_propは、糸で吊るされた操り人形(マリオネット)です。あなたが書くVerseコードは、 その糸を握る操者。「瞬間移動」は糸をパッと持ち上げてワープさせるイメージ、「なめらかな移動」は糸をゆっくり 一定のリズムで引っ張って優雅に歩かせるイメージです。

プロップをVerseから動かすには、まずいつもの「配線係」を1枚用意します。

verse
using { /Fortnite.com/Creative }
using { /Verse.org/Simulation }

my_scene_device := class(creative_device):
    # UEFNの詳細パネルで、動かしたいプロップをここに割り当てる
    @editable
    Box : creative_prop = creative_prop{}

    OnBegin<override>()<suspends> : void =
        Print("プロップの準備ができました")
🔌
creative_deviceが初めての方へ

class(creative_device)を継承した「配線係」に@editableでパーツを割り当て、OnBeginで処理を書く型は、ボタンやトリガーのときと完全に同じパターンです。詳しくは初級編・第11章を参照してください。

02やさしい

瞬間移動させる(TeleportTo)

いちばんシンプルな動かし方は、TeleportToです。指定した座標に、パッと一瞬でワープさせます。

verse — blink_prop_device.verse
using { /Fortnite.com/Devices }
using { /Fortnite.com/Creative }
using { /Verse.org/Simulation }

blink_prop_device := class(creative_device):
    @editable
    Box : creative_prop = creative_prop{}
    @editable
    ToggleButton : button_device = button_device{}

    var IsAtPointB : logic = false

    OnBegin<override>()<suspends> : void =
        ToggleButton.InteractedWithEvent.Subscribe(OnToggle)

    OnToggle(Agent : agent) : void =
        if (IsAtPointB?):
            Box.TeleportTo[vector3{X := 0.0, Y := 0.0, Z := 0.0}, IdentityRotation()]
        else:
            Box.TeleportTo[vector3{X := 0.0, Y := 0.0, Z := 400.0}, IdentityRotation()]
        set IsAtPointB = not IsAtPointB?

ボタンを押すたびに、プロップが2つの地点をパッパッと切り替わりながら移動します。TeleportToは座標(vector3)と 向き(rotation)の2つだけを受け取る、いちばんシンプルな移動命令です。

📝 演習問題 01

上のコードを参考に、Z := 400.0の代わりにX := 600.0方向(横)にワープするside_blink_deviceを作ってみましょう。 ボタンを押すたびに、原点と横に600離れた地点を行き来するようにしてください。

verse
side_blink_device := class(creative_device):
    @editable
    Box : creative_prop = creative_prop{}
    @editable
    ToggleButton : button_device = button_device{}

    var IsAtSide : logic = false

    OnBegin<override>()<suspends> : void =
        ToggleButton.InteractedWithEvent.Subscribe(OnToggle)

    OnToggle(Agent : agent) : void =
        if (IsAtSide?):
            Box.TeleportTo[vector3{X := 0.0, Y := 0.0, Z := 0.0}, IdentityRotation()]
        else:
            Box.TeleportTo[vector3{X := 600.0, Y := 0.0, Z := 0.0}, IdentityRotation()]
        set IsAtSide = not IsAtSide?
03ふつう

なめらかに動かす(MoveToEase)

瞬間移動ではなく、時間をかけてなめらかに動かしたいときはMoveToEaseを使います。 移動時間や速度変化(イージング)、そして「到着後どうするか」まで指定できる、より高機能な移動命令です。

verse — floating_platform_device.verse
floating_platform_device := class(creative_device):
    @editable
    Platform : creative_prop = creative_prop{}

    OnBegin<override>()<suspends> : void =
        Platform.MoveToEase(
            vector3{X := 0.0, Y := 0.0, Z := 400.0}, IdentityRotation(),
            vector3{X := 1.0, Y := 1.0, Z := 1.0},
            3.0,                          # 3秒かけて移動
            move_to_ease_type.EaseInOut,  # ゆっくり加速→ゆっくり減速
            animation_mode.PingPong)      # 到着したら自動で逆再生、を延々くり返す
引数役割
Position / Rotationどこへ、どの向きで到着するか
Scale到着時の大きさ(拡大縮小もできる)
Duration移動にかける秒数
EaseType速度変化のクセ(Linear / EaseIn / EaseOut / EaseInOutなど)
AnimationMode到着後の挙動(OneShot=1回だけ、PingPong=往復、Loop=同じ動きをくり返す)
📝 演習問題 02

animation_mode.PingPongをanimation_mode.OneShotに変え、移動時間を1.5秒、 イージングをmove_to_ease_type.EaseOutに変更した、1回だけ動くエレベーターのコードを書いてみましょう。

verse
elevator_device := class(creative_device):
    @editable
    Platform : creative_prop = creative_prop{}

    OnBegin<override>()<suspends> : void =
        Platform.MoveToEase(
            vector3{X := 0.0, Y := 0.0, Z := 400.0}, IdentityRotation(),
            vector3{X := 1.0, Y := 1.0, Z := 1.0},
            1.5,
            move_to_ease_type.EaseOut,
            animation_mode.OneShot)
04ふつう

現在地を記録して呼び戻す

チェックポイントやリセット機能でよく使うのが、「今の姿勢(位置・回転)をまるごと記録しておき、あとで正確にそこへ戻す」パターンです。

verse
checkpoint_prop_device := class(creative_device):
    @editable
    Door : creative_prop = creative_prop{}
    @editable
    ResetButton : button_device = button_device{}

    var SavedTransform : transform = transform{}

    OnBegin<override>()<suspends> : void =
        # 今の姿勢をまるごと記録しておく
        set SavedTransform = Door.GetGlobalTransform()
        ResetButton.InteractedWithEvent.Subscribe(OnReset)

    OnReset(Agent : agent) : void =
        # 記録しておいた姿勢に、ワンコマンドで正確に戻す
        Door.SetGlobalTransform(SavedTransform)
💾
セーブ&ロードのミニ版

「今の状態をまるごと記録して、あとで復元する」という考え方は、上級編・第11章のトランザクションで学ぶ「セーブ→挑戦→失敗したら自動ロード」の発想とよく似ています。UEFNのゲームでは、この小さな記録&復元パターンがいたるところで活躍します。

05応用

応用: 複数の経由地点を自動巡回する

2点間の往復を超えて、3か所以上をぐるぐる巡回させたいときはkeyframed_movement_componentを使います。

たとえ話でわかる キーフレームアニメーション

パラパラ漫画(紙芝居)を思い出してください。1枚1枚の絵を「キーフレーム」として順番に並べておけば、 めくるスピードを調整するだけで複雑な動きも滑らかに再生できます。keyframed_movement_componentは、 この「紙芝居めくり係」です。

verse — patrol_platform_device.verse
using { /Verse.org/SceneGraph/KeyframedMovement }

patrol_platform_device := class(creative_device):
    # UEFNの詳細パネルで、プロップに追加した「Keyframed Movement」コンポーネントを割り当てる
    @editable
    Movement : keyframed_movement_component = keyframed_movement_component{}

    OnBegin<override>()<suspends> : void =
        Keyframes : []keyframed_movement_delta = array{
            keyframed_movement_delta{                                     # 停留所1
                Transform := transform{Translation := vector3{X := 0.0, Y := 0.0, Z := 0.0}},
                Duration := 2.0, Easing := move_to_ease_type.EaseInOut
            },
            keyframed_movement_delta{                                     # 停留所2
                Transform := transform{Translation := vector3{X := 500.0, Y := 0.0, Z := 300.0}},
                Duration := 2.5, Easing := move_to_ease_type.EaseInOut
            },
            keyframed_movement_delta{                                     # 停留所3
                Transform := transform{Translation := vector3{X := 500.0, Y := 500.0, Z := 300.0}},
                Duration := 2.5, Easing := move_to_ease_type.EaseInOut
            }
        }
        Movement.SetKeyframes(Keyframes)
        Movement.Play()   # 停留所1→2→3の順に、自動でなめらかに巡回する
🛠️
この分野はアップデートが速い

Scene Graph関連のAPIはUEFNの中でも比較的新しく、細かいプロパティ名やコンポーネントの取得方法がバージョンごとに調整されることがあります。骨組みの考え方(キーフレーム配列を作ってSetKeyframes→Play)は変わりませんが、実際にUEFNで書くときはVerseエディタのオートコンプリート(Ctrl+Space)で最新の候補を確認する習慣をつけましょう。

📝 演習問題 03

停留所を4か所目(X:=0.0, Y:=500.0, Z:=300.0、Duration:=2.0)まで増やし、四角形をぐるっと1周するルートにしてみましょう。

まとめ & 演習チャレンジ

Prop.TeleportTo[Pos, Rot]

T := Prop.GetGlobalTransform()

📝 総合チャレンジ問題

ボタンを押すと、プロップが「①現在地を記録 → ②MoveToEaseで3秒かけて上空へ移動 → ③もう一度ボタンを押すと元の位置へ戻る」 という一連の動きをするlift_deviceを、これまでの章の知識を組み合わせて作ってみましょう。

ヒント: 02章の「押すたびに切り替わるトグル」と、04章の「記録して呼び戻す」を組み合わせます。
verse — lift_device.verse
lift_device := class(creative_device):
    @editable
    Lift : creative_prop = creative_prop{}
    @editable
    CallButton : button_device = button_device{}

    var GroundTransform : transform = transform{}
    var IsUp : logic = false

    OnBegin<override>()<suspends> : void =
        set GroundTransform = Lift.GetGlobalTransform()   # ①現在地を記録
        CallButton.InteractedWithEvent.Subscribe(OnCall)

    OnCall(Agent : agent) : void =
        if (IsUp?):
            # ③元の位置へなめらかに戻る
            Lift.MoveToEase(
                GroundTransform.Translation, GroundTransform.Rotation,
                vector3{X := 1.0, Y := 1.0, Z := 1.0}, 3.0,
                move_to_ease_type.EaseInOut, animation_mode.OneShot)
        else:
            # ②上空へなめらかに移動
            UpPosition := GroundTransform.Translation + vector3{X := 0.0, Y := 0.0, Z := 500.0}
            Lift.MoveToEase(
                UpPosition, GroundTransform.Rotation,
                vector3{X := 1.0, Y := 1.0, Z := 1.0}, 3.0,
                move_to_ease_type.EaseInOut, animation_mode.OneShot)
        set IsUp = not IsUp?
